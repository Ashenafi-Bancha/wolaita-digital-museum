## 🔄 How to Use Translations in Pages

### **Step 1: Import the hook**
```typescript
import { useLanguage } from '../../context/LanguageContext';
```

### **Step 2: Use in component**
```typescript
const MyPage = () => {
  const { t } = useLanguage();

  return (
    <div>
      <h1>{t('page.title')}</h1>
      <p>{t('page.subtitle')}</p>
      <button>{t('common.readMore')}</button>
    </div>
  );
};
```

### **Step 3: Test**
- Switch language using Globe icon selector
- All translated text should update instantly
